روش آپلود روی GitHub Pages

1. وارد مخزن insideout-proposal شوید.
2. تب Code را باز کنید.
3. گزینه Add file و سپس Upload files را بزنید.
4. تمام محتویات این بسته را با حفظ ساختار پوشه‌ها داخل ریشه مخزن آپلود کنید.
5. اگر GitHub درباره جایگزینی index.html یا فایل‌های قبلی هشدار داد، نسخه جدید را جایگزین کنید.
6. پایین صفحه گزینه Commit changes را بزنید.
7. بعد از 1 تا 5 دقیقه صفحه GitHub Pages را با Refresh سخت بازخوانی کنید.
